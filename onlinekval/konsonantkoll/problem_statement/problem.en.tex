\problemname{Consonant Check}
Your friend Frida loves consonants! Unfortunately, this causes problems for her when she types on the computer. She likes consonants so much that when there should be two of the same consonant in a row, Frida in her eagerness sometimes presses the key far too many times.

To help Frida, you should write a program that removes the extra consonants. In Swedish there are $20$ consonants: \textbf{bcdfghjklmnpqrstvwxz}. Conveniently, three or more of the same consonant never appear in a row in correct text.

\section*{Input}
The input consists of exactly one line, which will only contain lowercase letters (\texttt{a-z}) and possibly spaces. Spaces will never appear at the beginning or end of the line, and there will never be multiple spaces in a row (just like in a normal sentence). The line is between $1$ and $1000$ characters long.

\section*{Output}
Print the same line with excess consonants removed, so that there are never more than two of the same consonant in a row.

\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.
