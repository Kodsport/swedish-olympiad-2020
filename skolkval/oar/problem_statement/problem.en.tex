\problemname{Islands}
The 2020 International Olympiad in Informatics (IOI) will be held in Singapore, a small country by area that consists of lots of islands.
On one of the excursions at IOI, the $N$ participants will visit these islands.
But the participants are busy thinking about how to implement Fibonacci heaps, so one by one they get lost and cannot find their way back.

On the first island, one participant disappears, on the second island, another participant disappears.
If $a_i$ is the number of participants who disappear on island $i$, then $a_{k-2} + a_{k-1}$ disappear from island $k$ (or the number of remaining participants, if fewer remain).

\begin{figure}[h]
  \centering
      \includegraphics[width=1.0\textwidth]{oarfig}
      \caption{The figure shows the situation in the first sample when the last (twelfth) participant has disappeared on island number 5.}

On which island does the last participant disappear?

\section*{Input}
The first line contains an integer $1\le N \le 10\,000$, the number of participants.

\section*{Output}
An integer $A$, the number of the island where the $N$-th participant disappears.

\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.
